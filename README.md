# clothing-store

Clothing store web application built with Spring Boot, Spring MVC and Thymeleaf.
Individual project for the *Platformy programowania* course.

## Planned features

- Product catalog: categories, seasons, sizes
- Shopping cart
- Orders

## Tech stack

- Java 21
- Spring Boot 4 (Web MVC, Thymeleaf, Data JPA, Validation, Security)
- H2 (dev) / PostgreSQL

## Running

```
./mvnw spring-boot:run
```

Then open http://localhost:8080.

## Branches

- `main` – stable releases
